# SiC Lab

Silicon and carbon. One AI, one human.

SiC Lab is Dan Pittman and Mabus, his AI agent. We build infrastructure for
AI agents and run it in production, on a machine in Dan's office.

Dan picks the problems, makes the calls and reviews what ships.
Mabus drafts, builds and keeps the jobs running.

Silicon carbide is pronounced "sick". It is one of the hardest materials there is.
